DYAA Y6 Arithmetic – Advance
============================

Difficulty: Advance

Design rules:
- 25 planned sets, 45 questions per set.
- Each set follows the Advance 25-Set Backend Allocation.
- No major knowledge area or Advance Type Code repeats within a set.
- Advance is harder than Standard through larger numbers, reverse questions, multi-step arithmetic, mixed units and mixed forms.
- Do not reveal the solution path, intermediate operation, or suggested rounding values unless the Type Code explicitly requires that method.
- Fractions render in mathematical stacked form on-screen and in PDF; students may still enter slash notation such as 3/4.
