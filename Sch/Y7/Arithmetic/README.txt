Design:
- 25 planned Standard sets
- 45 questions per set
- 60 Major Knowledge Areas
- 420 Standard Fine Type Codes
- Each set uses 45 different Major Areas and 45 different Standard Type Codes.
- Y7 Standard is above Y6 Standard but remains arithmetic-focused rather than full Mathematical Reasoning.
- Repeatedly practised Y6 basics are not intended to occupy standalone Y7 question slots; they may still appear inside richer mixed, inverse or applied arithmetic.
