Y8 Scholarship Mathematics
==========================

This Y8 series was reset in v11.7 so that all new tests follow the reviewed systematic backend banks.

Authoritative Standard backend:
  DYAA_Y8_Mathematics_Standard_25_Set_Backend_Allocation_v1.0.xlsx

Authoritative Advance backend:
  DYAA_Y8_Mathematics_Advance_25_Set_Backend_Allocation_v1.0.xlsx

Standard design:
- 25 sets × 45 questions
- 66 Major Knowledge Areas
- 462 Standard Fine Type Codes
- Each set uses 45 different Major Areas and 45 different Standard Type Codes
- Usually 1–3 meaningful steps
- Covers Number & Arithmetic, Fractions/Decimals/Percentages, Ratio/Rates/Finance,
  Algebra, Measurement/Geometry, Data/Probability

Advance design:
- Same 66 Major Knowledge Areas
- 462 Advance Fine Type Codes
- 25 sets × 45 questions
- Each set uses 45 different Major Areas and 45 different Advance Type Codes
- Usually 3–5 meaningful steps where appropriate
- Reverse/original-value, mixed representations, constraints, optimisation,
  combined algebra and reverse/composite geometry occur much more often
- Advance is harder use of the same Y8 syllabus, not a separate reasoning syllabus

Common wording rule:
- English must be clear and natural
- Difficulty comes from the mathematics, not obscure wording
- Do not reveal the solution path or intermediate operation in the question

Current progress:
- Standard Tests 1–4 completed through v12.2
- Advance Tests 1–4 completed through v12.2

Legacy Y8 Arithmetic Test 1–8 and legacy Y8 Mathematical Reasoning Test 1 were removed
from the active v11.7+ catalog because they pre-dated the systematic Y8 backend design.
They remain available in earlier archived releases such as v11.6 if ever needed.

Set 3 recheck in v12.2: corrected Standard Q2 LCM time and clarified Standard Q12 crate wording; mathematical structure/type codes preserved.
